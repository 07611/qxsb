# 开发任务书摘要与实现映射

完整实现见仓库源码。本文件记录任务书的结构化摘要，方便评估时对照。

## 目标

Vue 3 + HTML5 + CSS3 + JavaScript，完成基于本地人脸情绪识别的歌曲推荐系统。支持图片、打开视频、实时摄像头、拍照获得人脸；本地算法得到情绪；情绪推荐歌曲。歌曲包含本地下载资源与在线 API。

## 已实现范围

- 27 项功能，逐项映射到 `README.md` 第 3 节和 `docs/architecture.json` 的 `features`。
- 98 个 REST 操作，统一 `/api/v1` 响应结构与错误处理。
- 23 个前台路由页面，5 个后台路由页面；均具备加载/错误/空状态与移动端单列布局。
- 本地 FER+ + YuNet 情绪模型；六张真实感演示人像，识别结果与标签一致。
- 本地曲目由算法真实分析；在线 iTunes API 提供 30 秒官方预览。
- 页面内 `/algorithms` 明确展示三套算法、公式、隐私边界与限制。

## 技术栈（锁定）

Vue 3 SPA / Vite / Element Plus；Python FastAPI；SQLite + SQLAlchemy；JWT Access + Refresh；Docker + Compose；Render；GitHub Actions。

## 关键业务规则

- bcrypt；邮箱唯一；5 次失败锁 15 分钟；统一“邮箱或密码错误”。
- 头像文件上传，不存二进制；昵称 2–20 且唯一；联系方式二次验证。
- 服务端 RBAC；401/403 分离；归属查询带 owner 条件；角色变更即时生效。
- 预签名直传、magic number、400/1200 缩略图、固定宽高。
- 两级分类、删除保护、冗余计数、热门标签。
- 搜索转义、分页、60 字高亮、搜索日志。
- 通知冗余未读数、一键已读、90 天归档。
- 后台统一鉴权、搜索筛选排序分页、危险操作审计。
- 限流按接口+维度、429 + Retry-After、10 秒幂等。
- JSON 日志、requestId、全局异常、前端捕获。
- 种子幂等、双账号、全状态演示数据、本地稳定资产。
- 验证码 6 位 5 分钟、60 秒重发、HMAC 哈希、一次性、IP 日限。
- OAuth state 一次性、独立账号、不按邮箱静默合并。
- 重置令牌 15 分钟一次性、撤销全部 Refresh Token、防枚举。
- 会话 IP 打码、单设备下线。
- 多语言语言包、Intl 格式化。
- 分享短码、过期、服务端 OG。
- 邮件异步、3 次重试、模板分离、频率限制、模板变量加密。
- 报表预聚合、单位精度、CSV + 审计。
- 工单状态机、原始描述锁定、通知/邮件。
- 缓存 TTL、写后删除、回源。
- 埋点批量、敏感字段过滤、HMAC 用户标识、漏斗/留存、归档。
- 推送频控、用户设置优先、夜间营销静默、模板。
- 注册审核/邀请码、pending 页。
- 短信日限、脱敏、留痕。
- 运营位定时上下线、数量上限、固定比例、链接白名单。
